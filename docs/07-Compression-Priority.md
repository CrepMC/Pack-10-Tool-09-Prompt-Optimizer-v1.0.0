# 07 — Compression Priority

Compress in this order:
1. duplicate language;
2. explanations/rationales;
3. redundant adjectives;
4. soft stylistic detail;
5. low-priority polish;
6. merge equivalent negative guards.

Never remove:
ProductLock;
hard ratio;
QA P0;
critical crop/product guards;
no-new-object/person if critical;
final-state constraints if failure history requires them.
