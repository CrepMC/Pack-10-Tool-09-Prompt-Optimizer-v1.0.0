# 02 — Source Precedence

Priority:
1. ProductLock/reference truth.
2. User/project hard constraints.
3. QA P0.
4. QA P1.
5. Locked execution plans.
6. Creative style.
7. Optional polish.

Example:
Creative says “editorial turn”, but QA says rear view causes product mutation and ProductDNA has front-only evidence.
The safe Product/QA constraint wins.
