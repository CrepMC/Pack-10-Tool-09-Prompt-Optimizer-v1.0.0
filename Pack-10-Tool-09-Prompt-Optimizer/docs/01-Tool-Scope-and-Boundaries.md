# 01 — Tool Scope and Boundaries

Prompt Optimizer trả lời: **với toàn bộ contract + QA, prompt generation cuối cần chứa điều gì, ưu tiên gì, bỏ gì, sửa gì và nén như thế nào?**

Owns:
conflict resolution, prompt assembly, minimal-delta repair, compression, block ordering, final validation, output length.

Does not own:
upstream planning decisions, ProductDNA edits, QA decision, video generation.
